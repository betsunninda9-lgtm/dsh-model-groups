# 0.3.10-beta.1 模型能力测试

本测试版针对 DSH 0.2.2-rc.1 网页模型设置，Node.js 22 或更新版本。

## 更新

用最终交付的固定提交安装命令更新原 profile；安装后重启同一个 DSH 引擎并刷新网页。插件设置页的前端、后端版本均应为 `0.3.10-beta.1`。执行“更新多密钥补丁”，随后再次重启同一个引擎并刷新网页。本次设置页和后端补丁必须一起更新。

## 设置位置

设置 → 模型 → 供应商 → 展开密钥分组。在模型列表上方启用“模型能力默认设置”。首次启用前选择：

- 保留现有设置：已有模型保留旧配置与目录继承，新模型跟随分组。
- 全部跟随分组：已有及新增模型都按分组规则处理。

识图与思考强度分别控制。模型详情中可分别选择跟随分组、单独开启或单独关闭；首次保留的旧模型另显示“保留原设置”。单独设置是例外，不受后续分组开关影响。全部恢复跟随分组会先要求确认，并只修改草稿。

所有设置都沿用原来的保存按钮。未保存退出不生效。

## 思考强度的含义

开启意味着给模型声明可选强度，不强制请求用“高”。已有有效的自定义档位和 API 参数值会保留；没有自定义档位时使用 DSH 原编辑器常用的 off、low、medium、high。中转站必须实际支持这些能力，开关不能替服务端添加识图或思考能力；不支持时请单独关闭或保留原配置。

## 建议实机验收

1. 在包含旧模型的分组中选择保留现有设置并启用规则，保存后退出设置再进入，原模型配置保持不变。
2. 拉取并添加一个新模型，确认自动跟随两个分组开关。重复拉取时，已有条目的单独设置应保留。
3. 对某个模型单独关闭识图，切换分组默认开关，确认该模型仍关闭。另一个没有例外的模型应跟随。
4. 保存并刷新网页，在聊天模型选择中选取对应模型，核对图片输入和思考强度选择是否与设置一致。
5. 自定义思考档位 API 值后切换分组开关，重新开启时确认自定义值仍在。
6. 修改后取消编辑、分组排序、模型排序、普通单密钥供应商及其它模型设置均保持原有行为。

自动测试使用公开程序副本和合成配置验证；真实中转站、手机触摸和视觉布局仍需要实机确认。
