# 0.3.10 模型能力批量开关

适用于 DSH 0.2.2-rc.1 网页模型设置，Node.js 22 或更新版本。

## 更新

使用 `dsh plugin --profile web add dsh-model-groups@0.3.10 --registry=https://registry.npmjs.org/` 更新原 profile（如非 web，请替换配置名）；安装后重启同一个 DSH 引擎并刷新网页。插件设置页的前端、后端版本均应为 `0.3.10`。执行“更新多密钥补丁”，随后再次重启同一个引擎并刷新网页。本次设置页和后端补丁必须一起更新。

## 设置位置

设置 → 模型 → 供应商 → 展开密钥分组。模型列表上方只保留两个批量开关：识图、思考强度设置。原来的模型行、模型详情和单独能力控件保持原样，不显示跟随选择、能力摘要、例外计数或首次启用选择。

- 开启某项：当前组所有模型一起开启该项。
- 关闭某项：当前组所有模型一起关闭该项。
- 随后可以进入模型详情，用原来的控件单独调整。
- 新增或拉取到的新模型沿用该组最近一次批量开关。重复拉取不会覆盖已有模型的单独修改。
- 再次操作批量开关时，会重新统一修改当前所有模型，包括此前单独修改过的模型。

两个开关彼此独立；只操作识图不会改变思考设置。所有修改沿用原来的保存按钮，未保存退出不生效。beta.1 的规则会转换为原生模型字段，保存时清理旧的跟随元数据，升级后现有实际能力保持不变。

## 思考强度的含义

开启表示给模型声明可选强度，不强制请求使用“高”。已有有效的自定义档位和 API 参数值在本次开启时保留；没有自定义档位时使用常用的 off、low、medium、high。中转站必须实际支持这些能力。

## 建议实机验收

1. 先确认每个模型的展开详情与原版相同，没有新增的跟随选择或状态行。
2. 在分组打开识图并保存，退出再进入，所有模型开启识图；关闭并保存，所有模型关闭。
3. 批量打开后，用原模型控件单独关闭一个模型，保存、刷新、重新拉取列表；这个单独修改应保留。
4. 新增一个模型，核对它采用最近一次分组开关；原模型的单独修改保持不变。
5. 再次关闭、开启分组开关，当前所有模型应再次统一；只操作识图时思考档位不变化。
6. 保存后在聊天中选取对应模型，核对图片入口和思考选择。修改后取消编辑、原有排序及普通供应商不受影响。

自动测试使用公开程序副本和合成配置；真实中转站、手机触摸与视觉布局仍需实机确认。
